# Digital Dice using Arduino & LCD

## Description
A simple digital dice project using Arduino Uno, a push button, and a 16x2 LCD. When the button is pressed, a random number between 1 and 6 is displayed on the LCD and stays until the next press.

## Components
- Arduino Uno  
- 16x2 LCD (without potentiometer/resistor)  
- Push Button  
- Proteus for simulation  

## How It Works
- Press the button → Display a number (1–6)  
- LCD holds the number until the next press  
- Works cleanly in Proteus
